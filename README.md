# Fall 2026 Project: Mixed Grade Class

This project is being created by 5in’s Mixed Grade Coding Class during the fall of 2026.

The website for this project is available at [https://5in-tw.github.io/2026-fall-mx/](https://5in-tw.github.io/2026-fall-mx/)

## Software needed for this project

### VS Code

To edit our code (HTML, CSS, and JavaScript) files, we use **VS Code**.

1. [Download VS Code](https://code.visualstudio.com).
2. Double-click the VS Code installer.
3. Click “Install”.

### Git

To share our code with everyone and to keep track of changes to our code, we use **Git**.

1. [Download Git](https://git-scm.com/install/windows).
2. Double-click the “Git-2.55.0.5” installer (the number may be larger than 2.55).
3. Click “Next” button until you see “Choosing the default editor used by Git”. For the option “Choosing the default editor used by Git”:
   1. Choose the option “Use Visual Studio Code as Git's default editor”.
   2. Click “Next”.
4. For the option “Adjusting the name of the initial branch in new repositories”:
   1. Choose the second option, “Override the default branch name for new repositories”.
   2. Click “Next“.
5. Click “Next” until you see the “Install” button.
   - Click “Install”.
6. Uncheck the “View Release Notes” checkbox.
   - Click “Finish”.
7. In VS Code, click the “Source Control” button on the left-side Activity Bar; it's just below the Search button.
   - If you see a “Download Git for Windows” button, click the “reload” link just below that button.

#### Configure your Git username:

Your Git username and email address is how others will see you when looking at the list of changes on our website.

1. In VS Code, click the “Terminal” button.
2. Use this command to set your name. Replace `Mona Lisa` with your name.

   ```sh
   git config --global user.name "Mona Lisa"
   ```
3. Use this command to set your email. replace `mona@gmail.com` with your 5in email address.

   ```sh
   git config --global user.email "mona@gmail.com"
   ```
